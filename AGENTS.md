Любой русский текст, который ты пишешь сам (ответ в чате, объяснение, конспект, карточки, ячейки ноутбука), пиши по [docs/STYLE.md](docs/STYLE.md). Он действует всегда, вместе с правилами жанра ниже.

Правила для отдельных видов работы лежат в [docs/](docs/). Прежде чем начать такую работу, прочитай нужный файл и работай строго по нему:

- Конспект материала (обычно присылаю HTML урока или статьи): [docs/NOTES.md](docs/NOTES.md).
- Объяснение или разбор материала (формула, тема, глава, лекция, лаба «с объяснением в формате урока»): [docs/MENTOR.md](docs/MENTOR.md).
- Карточки Anki по пройденным темам: [docs/ANKI.md](docs/ANKI.md).
