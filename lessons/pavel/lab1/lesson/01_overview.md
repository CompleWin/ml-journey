# ЛР1 Павла: краткий обзор

## Что это за лаба

Название: «Введение в язык программирования Python». По сути это вводная по описательной статистике
на Python: сгенерировать датасет, посчитать по нему базовые статистики **руками** и нарисовать три вида графиков.

**Вариант 2, «Интернет-магазин».**

| признак | что это | распределение по варианту | в коде |
|---|---|---|---|
| `unit_price` | цена одной штуки | Exp(40) | `np.random.exponential(scale=40)` → среднее 40 |
| `qty` | штук в заказе | Pois(2) | `np.random.poisson(lam=2)`, нули выкидываем |
| `discount` | скидка, доля | U(0, 0.35) | `np.random.uniform(0, 0.35)` |
| `delivery_fee` | доставка | U(0, 25) | `np.random.uniform(0, 25)` |

Вычисляемые признаки:

* `subtotal = unit_price · qty` (сумма без скидки и доставки);
* `discount_value = subtotal · discount` (скидка в деньгах);
* `avg_item_cost = subtotal / qty` (средняя цена позиции, совпадает с `unit_price`);
* `order_total = unit_price · qty · (1 − discount) + delivery_fee` (целевой признак).

## Что требуется сделать

1. Сгенерировать датасет по варианту (у Павла n = 10 000).
2. Для **каждого** поля: математическое ожидание (выборочное среднее) и дисперсию.
3. Выбросы по правилу трёх сигм для каждого поля.
4. Коэффициенты корреляции между полями (матрица).
5. Графики: точечный с выделенными выбросами, гистограмма, тепловая карта корреляций.
6. **Проверить, соответствует ли гистограмма заданному распределению.**

**Правила, которые проверяют на сдаче:**

* можно только `numpy`, `pandas`, `matplotlib`, `seaborn`;
* всё, кроме генерации случайных чисел, считается вручную. Из numpy/pandas разрешены только
  `+ − × ÷`, степень и корень. То есть `np.mean`, `np.var`, `df.std()`, `df.corr()` нельзя.

**Сдача:** отчёт + 2 случайных вопроса из списка (ответы в методичке, раздел 9) + показать преподавателю,
что владеешь кодом. Последнее для Павла самое опасное, поэтому урок и строим как live-coding.
