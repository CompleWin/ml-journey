### 1. Точки экстремума функции

Экстремум — это точка минимума или максимума функции.

- Локальный минимум — значение в точке меньше, чем во всех соседних точках.

- Глобальный минимум — наименьшее значение на всей области.

Максимумы определяются так же, только наоборот.

Необходимое условие экстремума: все частные производные равны нулю, то есть \(\nabla f(x) = 0\). Такие точки называются стационарными.

Условие не достаточное, потому что стационарной бывает и седловая точка: в одном направлении функция растёт, в другом падает.

Тип точки определяют по матрице вторых производных (матрице Гессе):

| Собственные значения | Тип точки |
| -------------------- | --------- |
| Все положительные    | Минимум   |
| Все отрицательные    | Максимум  |
| Разных знаков        | Седло     |

У функции Била в области три стационарные точки: минимум \((3, 0.5)\) и две седловые \((0, 1)\) и \((0.1, -2.64)\).

### 2. Одномерная и многомерная оптимизация

Одномерная оптимизация — поиск минимума функции одной переменной \(f(x)\). Движение возможно только вправо или влево, поэтому можно сжимать отрезок вокруг минимума.

Многомерная оптимизация — поиск минимума функции нескольких переменных \(f(x_1, \dots, x_n)\). Направлений бесконечно много, поэтому сначала надо выбрать направление, например антиградиент.

В наискорейшем спуске используются обе:

- Многомерная задача — найти точку \((x, y)\).

- Одномерная задача — на каждом шаге найти \(\alpha\), то есть минимум функции \(\varphi(\alpha) = f(x_t - \alpha \nabla f(x_t))\).

### 3. Выбор оптимальной точки старта

Заранее оптимальную точку обычно не знают. Как правило, выбирают случайную точку из области допустимых значений.

От старта зависит, куда придёт алгоритм и за сколько шагов. На функции Била:

| Старт     | Результат                              |
| --------- | -------------------------------------- |
| \((0, 0)\)   | Минимум за 220 шагов                |
| \((-1, -1)\) | Минимум за 510 шагов                |
| \((-2, -2)\) | Вышел из области за 5276 шагов      |
| \((0, 1)\)   | Седло, градиент равен нулю, шагов нет |

Из 1369 точек сетки до глобального минимума дошли 664, то есть 48.5%.

Что делать на практике:

- Запустить алгоритм из нескольких случайных точек и взять лучший результат (мультистарт).

- Использовать знания о задаче, если известно, где примерно лежит минимум.

- Не стартовать в стационарной точке, там градиент равен нулю и алгоритм сразу остановится.

### 4. Гиперпараметры алгоритма и как их подбирать

Гиперпараметры — настройки, которые задаём мы, а не находит сам алгоритм.

| Гиперпараметр         | Что задаёт                       | В лабе            |
| --------------------- | -------------------------------- | ----------------- |
| Начальная точка       | Откуда стартуем                  | \((-1, -1)\)      |
| \(\varepsilon_1\)     | Минимальный сдвиг точки          | \(10^{-8}\)       |
| \(\varepsilon_2\)     | Минимальное изменение функции    | \(10^{-14}\)      |
| \(\varepsilon_3\)     | Минимальная норма градиента      | \(10^{-6}\)       |
| Отрезок для \(\alpha\) | Где ищем шаг                    | \([0, 1]\)        |
| Точность дихотомии    | Насколько точно ищем шаг         | \(10^{-8}\)       |
| `max_iter`            | Предел числа итераций            | 10 000            |

В обычном градиентном спуске главный гиперпараметр — постоянный шаг \(\alpha\). В наискорейшем он подбирается автоматически, поэтому вместо него задают отрезок поиска.

Подбирают опытным путём: запускают с разными значениями и смотрят на число шагов и результат.

Пример для \(\varepsilon_2\), старт \((-1, -1)\):

| \(\varepsilon_2\) | Шагов | Значение функции      |
| ----------------- | ----- | --------------------- |
| \(10^{-4}\)       | 42    | \(1.5 \cdot 10^{-3}\) |
| \(10^{-8}\)       | 231   | \(2.2 \cdot 10^{-7}\) |
| \(10^{-12}\)      | 445   | \(2.2 \cdot 10^{-11}\) |

Пример для верхней границы отрезка:

| Отрезок для \(\alpha\) | Шагов |
| ---------------------- | ----- |
| \([0, 0.01]\)          | 3873  |
| \([0, 0.1]\)           | 919   |
| \([0, 1]\)             | 510   |
| \([0, 5]\)             | 494   |

Важно: слишком большие \(\varepsilon\) останавливают алгоритм раньше времени, слишком маленькие заставляют считать лишние шаги. Слишком короткий отрезок обрезает шаг, и метод превращается в спуск с постоянным шагом.

### 5. Алгоритм работы метода градиентного спуска

1. Выбираем начальную точку \(x_0\).

2. Считаем градиент \(\nabla f(x_t)\) в текущей точке.

3. Выбираем размер шага \(\alpha\). В обычном методе он постоянный, в наискорейшем находится из условия \(\alpha_t = \arg\min \, f(x_t - \alpha \nabla f(x_t))\).

4. Делаем шаг против градиента: \(x_{t+1} = x_t - \alpha_t \nabla f(x_t)\).

5. Проверяем критерии остановки:

- \(||x_{t+1} - x_t|| \leq \varepsilon_1\)

- \(|f(x_{t+1}) - f(x_t)| \leq \varepsilon_2\)

- \(||\nabla f(x)|| \leq \varepsilon_3\)

Если выполняется любой из критериев, останавливаемся. Иначе возвращаемся к пункту 2.

Идём против градиента, потому что градиент показывает направление самого быстрого роста функции, а нам нужно самое быстрое убывание.

В наискорейшем спуске соседние шаги перпендикулярны, поэтому траектория идёт зигзагом.

### 6. Алгоритмы одномерной численной оптимизации

- Перебор по сетке — считаем функцию в точках с постоянным шагом и берём лучшую. Просто, но дорого.

- Метод дихотомии — берём две точки рядом с серединой отрезка, сравниваем значения и выбрасываем половину, где минимума нет.

- Метод золотого сечения — делим отрезок в пропорции 0.618. Одна из точек переходит на следующий шаг, поэтому на итерацию нужно одно новое вычисление функции.

- Метод Фибоначчи — похож на золотое сечение, но пропорции берутся из чисел Фибоначчи. Подходит, когда число вычислений задано заранее.

- Метод парабол — проводим параболу через три точки и переходим в её вершину. Быстрый на гладких функциях.

- Метод Ньютона — ищем ноль производной по формуле \(\alpha_{k+1} = \alpha_k - \varphi'(\alpha_k) / \varphi''(\alpha_k)\). Очень быстрый, но нужны первая и вторая производные.

- Backtracking (правило Армихо) — берём большой шаг и уменьшаем его, пока функция не упадёт достаточно. Точного минимума не ищет, зато дёшево.

| Метод             | Вычислений \(\varphi\) на итерацию | Остаётся от отрезка |
| ----------------- | ---------------------------------- | ------------------- |
| Дихотомия         | 2                                  | ≈ 0.5               |
| Золотое сечение   | 1                                  | ≈ 0.618             |

Методы дихотомии, золотого сечения и Фибоначчи требуют, чтобы на отрезке был один минимум (функция унимодальна). Производные им не нужны.

В лабе используется метод дихотомии.
