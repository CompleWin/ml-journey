# Урок 2. Линейные комбинации, линейная оболочка и базис

## Координаты — это скаляры

- Базисные векторы плоскости:
  - $\hat{\imath}$ («i с крышкой») — единичный вектор вправо, вдоль x;
  - $\hat{\jmath}$ («j с крышкой») — единичный вектор вверх, вдоль y.
- Каждая координата — скаляр, который растягивает свой базисный вектор, а вектор — сумма результатов:

$$
\begin{bmatrix} 3 \\ -2 \end{bmatrix} = 3\hat{\imath} + (-2)\hat{\jmath}
$$

- Пара $\hat{\imath}, \hat{\jmath}$ — **базис** стандартной системы координат.

## Базис можно выбрать другой

- Возьмём любые два **непараллельных** вектора — через них тоже получится любой вектор плоскости.
- Одни и те же числа в разных базисах задают **разные** векторы.
- Вывод: числовая запись вектора всегда зависит от выбранного базиса.

## Линейная комбинация

$$
a\vec{v} + b\vec{w}, \qquad a, b \text{ — любые числа}
$$

Почему «линейная»: если менять только один скаляр, конец вектора бежит по прямой через начало координат.

## Линейная оболочка (span)

**Линейная оболочка** — множество всех линейных комбинаций данных векторов, то есть всё, куда можно дойти, только складывая и масштабируя их.

| Векторы в 2D        | Линейная оболочка             |
| ------------------- | ----------------------------- |
| Два непараллельных  | Вся плоскость                 |
| Два на одной прямой | Прямая                        |
| Оба нулевые         | Одна точка (начало координат) |

Удобный приём: один вектор — стрелка, а **много векторов — точки** на их концах. Тогда линейная оболочка — это прямая, плоскость и т. д.

### Линейная оболочка в 3D

- Два непараллельных вектора → **плоскость** через начало координат.
- Добавляем третий вектор $\vec{u}$ в комбинацию $a\vec{v} + b\vec{w} + c\vec{u}$:
  - $\vec{u}$ лежит в этой плоскости → линейная оболочка **не растёт**;
  - $\vec{u}$ торчит из плоскости → линейная оболочка = **всё 3D-пространство**.

## Линейная зависимость

- **Линейно зависимые** векторы: один можно убрать, и линейная оболочка не уменьшится. То же самое: один вектор — линейная комбинация остальных.
  - Пример: $\begin{bmatrix} -6 \\ 4 \end{bmatrix} = -2 \begin{bmatrix} 3 \\ -2 \end{bmatrix}$, линейная оболочка этих двух — прямая.
- **Линейно независимые** векторы: каждый добавляет линейной оболочке новое измерение.

## Строгое определение базиса

**Базис** пространства — набор **линейно независимых** векторов, линейная оболочка которых равен **всему пространству**.

- «Порождают всё пространство» — достаём любой вектор.
- «Линейно независимы» — ни одного лишнего, запись вектора через базис единственная.
