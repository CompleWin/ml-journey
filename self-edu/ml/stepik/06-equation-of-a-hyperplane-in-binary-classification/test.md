### **Подвиг 3.**

![](assets\3609aa671a9d3377d839f08e70a3304db2a60ebf.png)

Уравнение прямой можно построить через две точки $\frac{x-x_1}{x_2-x_1}=\frac{y-y_1}{y_2-y_1}$

$A = (-3;1) B=(3; 5) => \frac{x+3}{6}=\frac{y-1}{4} => 6y=4x+18 => 4x - 6y + 18 = 0$

$y + kx + b = 0 => w=[b, k, y]$

Ответ: $w=[18, 4, -6]^T$
