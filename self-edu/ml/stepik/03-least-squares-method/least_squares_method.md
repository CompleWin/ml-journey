# Метод наименьших квадратов

## Постановка задачи

Измеряли некоторую функциональную зависимость. Из-за погрешностей приборов и других помех точки легли не точно на график, а с разбросом вокруг него.

Есть $N$ наблюдений:

$$
(x_i, y_i), \quad i = 1, 2, \dots, N
$$

Вид зависимости считается известным: его видно на графике или он известен заранее. Неизвестны только параметры. Задача — подобрать их так, чтобы функция наилучшим образом описывала данные.

Пример — линейная зависимость, где нужно найти два параметра $k$ и $b$:

$$
f(x) = kx + b
$$

Вид функции может быть и другим: парабола, синусоида, сумма известных функций. Линейный случай разбирается первым, потому что он самый простой.

---

## Критерии качества аппроксимации

**Аппроксимация** — приближение экспериментальных данных функцией выбранного вида.

Чтобы сравнивать параметры между собой, нужна числовая мера качества. Вариантов много:

- Сумма квадратов отклонений:

$$
E = \sum_{i=1}^{N} \big(y_i - f(x_i)\big)^2 \to \min
$$

- Сумма модулей отклонений:

$$
E = \sum_{i=1}^{N} \big|y_i - f(x_i)\big| \to \min
$$

- Наибольшее по модулю отклонение (минимакс):

$$
E = \max_i \big|y_i - f(x_i)\big| \to \min
$$

Каждый критерий даёт свой алгоритм. **Метод наименьших квадратов (МНК)** использует первый — минимум суммы квадратов ошибок.

---

## Почему именно квадраты

Выбор квадратов обоснован, если ошибки измерений распределены по **нормальному (гауссовскому) закону** с центром в истинном значении функции:

$$
p\big(y_i \mid x_i\big) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{\big(y_i - f(x_i)\big)^2}{2\sigma^2}\right)
$$

Где:

- $\sigma$ — стандартное отклонение (СКО) наблюдений $y_i$ от функции $f(x_i)$.
- $p(y_i \mid x_i)$ — плотность распределения вероятностей (ПРВ) наблюдения $y_i$ при данном $x_i$.

Чем ближе измерение к значению функции, тем больше плотность.

Измерения выполняются независимо, поэтому совместная плотность для всех точек равна произведению:

$$
L = \prod_{i=1}^{N} p\big(y_i \mid x_i\big) = \left(\frac{1}{\sigma\sqrt{2\pi}}\right)^N \exp\left(-\frac{1}{2\sigma^2}\sum_{i=1}^{N}\big(y_i - f(x_i)\big)^2\right)
$$

Лучшая функция $f$ та, при которой $L$ максимально. Дальше упрощаем:

1. Множитель перед экспонентой от $f$ не зависит, его отбрасываем.
2. Экспонента максимальна, когда её показатель с минусом минимален.
3. Множитель $\frac{1}{2\sigma^2}$ положение минимума не меняет, его тоже отбрасываем.

Остаётся критерий МНК:

$$
E = \sum_{i=1}^{N} \big(y_i - f(x_i)\big)^2 \to \min
$$

Итог: при гауссовском шуме минимизация суммы квадратов даёт самые правдоподобные параметры. Это частный случай **метода максимального правдоподобия**.

## Поиск минимума

Пусть функция зависит от параметров $\theta_1, \theta_2, \dots, \theta_m$:

$$
f(x) = f(x; \theta_1, \dots, \theta_m)
$$

Тогда $E$ — функция этих параметров:

$$
E(\theta_1, \dots, \theta_m) = \sum_{i=1}^{N} \big(y_i - f(x_i; \theta_1, \dots, \theta_m)\big)^2
$$

В точке экстремума производная равна нулю. Для функции нескольких переменных берём частную производную по каждому параметру и приравниваем к нулю:

$$
\frac{\partial E}{\partial \theta_j} = -2\sum_{i=1}^{N} \big(y_i - f(x_i)\big)\frac{\partial f(x_i)}{\partial \theta_j} = 0, \quad j = 1, \dots, m
$$

Получаем систему из $m$ уравнений с $m$ неизвестными. Если $f$ линейна по параметрам, система тоже линейная.

---

## МНК для линейной функции

$$
f(x) = kx + b
$$

Частные производные по параметрам:

$$
\frac{\partial f}{\partial k} = x, \qquad \frac{\partial f}{\partial b} = 1
$$

Подставляем в систему (множитель $-2$ сокращается):

$$
\begin{cases}
\sum_{i=1}^{N} (y_i - kx_i - b)\,x_i = 0 \\
\sum_{i=1}^{N} (y_i - kx_i - b) = 0
\end{cases}
$$

Раскрываем скобки:

$$
\begin{cases}
k\sum x_i^2 + b\sum x_i = \sum x_i y_i \\
k\sum x_i + bN = \sum y_i
\end{cases}
$$

Делим оба уравнения на $N$:

$$
\begin{cases}
k\,\frac{1}{N}\sum x_i^2 + b\,\frac{1}{N}\sum x_i = \frac{1}{N}\sum x_i y_i \\
k\,\frac{1}{N}\sum x_i + b = \frac{1}{N}\sum y_i
\end{cases}
$$

### Экспериментальные моменты

Средние суммы в системе — это выборочные (экспериментальные) моменты. Звёздочка означает, что они посчитаны по данным:

| Обозначение | Формула | Смысл |
| --- | --- | --- |
| $m_x^*$ | $\frac{1}{N}\sum x_i$ | первый начальный момент $x$ (среднее) |
| $m_y^*$ | $\frac{1}{N}\sum y_i$ | первый начальный момент $y$ (среднее) |
| $\alpha_2^*$ | $\frac{1}{N}\sum x_i^2$ | второй начальный момент $x$ |
| $\alpha_{11}^*$ | $\frac{1}{N}\sum x_i y_i$ | смешанный начальный момент |

Система принимает вид:

$$
\begin{cases}
k\,\alpha_2^* + b\,m_x^* = \alpha_{11}^* \\
k\,m_x^* + b = m_y^*
\end{cases}
$$

### Решение

Из второго уравнения $b = m_y^* - k\,m_x^*$. Подставляем в первое и получаем:

$$
k = \frac{\alpha_{11}^* - m_x^*\,m_y^*}{\alpha_2^* - (m_x^*)^2}, \qquad b = m_y^* - k\,m_x^*
$$

Смысл формулы для $k$: числитель — выборочная ковариация $x$ и $y$, знаменатель — выборочная дисперсия $x$:

$$
k = \frac{\operatorname{cov}(x, y)}{\operatorname{D}x}
$$

Формула для $b$ означает, что прямая МНК всегда проходит через точку средних $(m_x^*, m_y^*)$.

### Другие зависимости

Так же решается задача для любой функции, линейной по параметрам. Например, для параболы:

$$
f(x) = ax^2 + bx + c
$$

Здесь три параметра, значит три уравнения. Их решение даёт параболу с минимальной суммой квадратов отклонений.

## Реализация на Python

Нужны библиотеки `numpy` (векторные и матричные вычисления) и `matplotlib` (графики):

```bash
pip install numpy matplotlib
```

### Моделирование данных

Берём известную прямую, добавляем к ней гауссовский шум и проверяем, насколько точно МНК восстановит $k$ и $b$.

```python
import numpy as np
import matplotlib.pyplot as plt

N = 100     # число экспериментов
sigma = 3   # стандартное отклонение наблюдаемых значений
k = 0.5     # теоретическое значение параметра k
b = 2       # теоретическое значение параметра b

x = np.array(range(N))                    # x = [0, 1, ..., N-1]
f = np.array([k*z + b for z in range(N)]) # истинная прямая
y = f + np.random.normal(0, sigma, N)     # наблюдения с шумом

plt.scatter(x, y, s=2, c='red')
plt.grid(True)
plt.show()
```

`np.random.normal(0, sigma, N)` возвращает $N$ случайных чисел из нормального распределения со средним $0$ и СКО `sigma`.

### Вычисление коэффициентов

Код повторяет формулы из теории:

```python
mx = x.sum() / N               # m_x*
my = y.sum() / N               # m_y*
a2 = np.dot(x.T, x) / N        # alpha_2*
a11 = np.dot(x.T, y) / N       # alpha_11*

kk = (a11 - mx*my) / (a2 - mx**2)
bb = my - kk*mx
```

`np.dot(x.T, x)` — скалярное произведение вектора на себя, то есть сумма квадратов:

$$
x^T x = \sum_{i=1}^{N} x_i^2
$$

Аналогично `np.dot(x.T, y)` даёт $\sum x_i y_i$. Для одномерного массива `.T` ничего не меняет, поэтому можно писать просто `np.dot(x, x)`.

### Сравнение с истинной прямой

```python
ff = np.array([kk*z + bb for z in range(N)])

plt.plot(f)              # истинная прямая
plt.plot(ff, c='red')    # аппроксимация МНК
plt.show()
```

Две прямые почти совпадают. Пример запуска: $k = 0.491$, $b = 2.625$ при истинных $0.5$ и $2$. Значения меняются от запуска к запуску из-за случайного шума.

### Проверка

В `numpy` МНК для полиномов уже реализован. Результат совпадает с ручным расчётом:

```python
kk, bb = np.polyfit(x, y, 1)   # 1 — степень полинома
```

## Главное

- МНК подбирает параметры функции известного вида так, чтобы сумма квадратов отклонений от наблюдений была минимальной.
- Квадраты обоснованы гауссовским шумом: тогда МНК даёт самые правдоподобные параметры.
- Минимум ищут, приравнивая к нулю частные производные $E$ по каждому параметру.
- Для прямой $f(x) = kx + b$ решение выражается через выборочные моменты:

$$
k = \frac{\alpha_{11}^* - m_x^*\,m_y^*}{\alpha_2^* - (m_x^*)^2}, \qquad b = m_y^* - k\,m_x^*
$$
