Задание 3. Взлом и починка Top-K Sparse Autoencoder на актива-
циях Pythia-70m
Введение и контекст
Разреженные автоэнкодеры (Sparse Autoencoders, SAE) позволяют разложить скрытые
репрезентации трансформеров на интерпретируемые моносемантичные признаки. В
отличие от классических L1-SAE, где разреженность достигается штрафом за регуля-
ризацию, в архитектуре Top-K SAE (OpenAI / Gao et al., 2024) разреженность задается
жестко: ровно 𝐾самых активных нейронов пропускаются дальше, а остальные зану-
ляются.
Ниже приведен прототип автоэнкодера, перехватывающего residual stream 3-го слоя
модели EleutherAI/pythia-70m (𝑑= 512, словарь 𝐷= 2048, 𝐾= 32). Код содержит
три критические архитектурные ошибки/ловушки, из-за которых модель коллап-
сирует: Explained Variance не поднимается выше 50-60%, а более 40% признаков стано-
вятся «мертвыми».
import torch
import torch.nn as nn
class BrokenTopKSAE(nn.Module):
def __init__(self, d_model=512, d_sae=2048, k=32):
super().__init__()
self.k = k
self.W_enc = nn.Parameter(torch.randn(d_model, d_sae) * 0.02)
self.b_enc = nn.Parameter(torch.zeros(d_sae))
self.W_dec = nn.Parameter(torch.randn(d_sae, d_model) * 0.02)
self.b_dec = nn.Parameter(torch.zeros(d_model))
def encode(self, x):
pre_acts = x @ self.W_enc + self.b_enc
val, idx = torch.topk(pre_acts, self.k, dim=-1)
acts = torch.zeros_like(pre_acts).scatter_(-1, idx, val)
return acts
