# Конспект для тетради: Top-K Sparse Autoencoder (задание 3)

## 1. Цель

**Sparse Autoencoder (SAE)** — отдельная нейросеть, которая учится восстанавливать внутренние активации языковой модели, используя **малое количество одновременно активных признаков**.

В лабораторной:

- **Pythia-70m** — уже обученная языковая модель, её веса **не обновляются**.
- С выбранного блока Pythia снимают **активации** — внутренние контекстные векторы токенов.
- **SAE обучается** восстанавливать эти активации.
- Сравнивают **сломанный SAE** и **исправленный SAE**.

**Не путать:** *входной эмбеддинг* извлекается по ID токена из матрицы эмбеддингов; *активация блока* вычисляется после обработки токена в контексте. В этой задаче используется **активация**, не исходный эмбеддинг.

## 2. Важные размеры

| Обозначение | Значение | Смысл |
|---|---:|---|
| `d_model` | 512 | координат у одного вектора Pythia |
| `d_sae` | 2048 | потенциальных латентов SAE |
| `k` | 32 | максимум активных латентов на токен |
| `batch_size` | 64 | векторов на шаг обучения |
| `steps` | 1000 | обновлений параметров SAE |
| `X.shape` | `[65024, 512]` | 65 024 вектора по 512 чисел |

`2048 / 512 = 4`: словарь SAE в 4 раза шире входа. `32 / 2048 = 1,5625%`: одновременно активна не более чем небольшая часть словаря.

## 3. Как работает SAE

```text
Активация Pythia x: 512 чисел
            ↓
Энкодер: 512 → 2048 оценок признаков
            ↓
Top-K: оставить 32 максимальных оценки
            ↓
ReLU (в исправленной версии): отрицательные → 0
            ↓
Разреженный код acts: 2048 чисел, максимум 32 ненулевых
            ↓
Декодер: 2048 → 512
            ↓
Восстановление x_hat
            ↓
Сравнение x_hat с x, обновление весов SAE
```

**Развёрнуто:** каждый латент считает взвешенную сумму входных чисел; Top-K выбирает самые сильные оценки; декодер складывает векторы выбранных признаков с соответствующими коэффициентами.

Формулы:

```text
pre_acts = x @ W_enc + b_enc
acts = TopK(pre_acts)
x_hat = acts @ W_dec + b_dec
```

В исправленном варианте энкодер сначала использует `x - b_dec`, после Top-K применяет `ReLU`, а строки декодера нормируются по L2-норме.

**Формы в батче:**

```text
x       [64, 512]
W_enc   [512, 2048]
pre     [64, 2048]
acts    [64, 2048]
W_dec   [2048, 512]
x_hat   [64, 512]
```

## 4. Команды PyTorch, которые нужно запомнить

| Команда | Что делает |

| `torch.zeros(n)` | массив из `n` нулей |

| `torch.topk(x, k, dim=-1)` | `k` максимальных значений и их индексы по последней оси |
| `torch.zeros_like(x)` | нули той же формы, что `x` |
| `.scatter_(-1, idx, val)` | вставить значения `val` на позиции `idx` |

`dim=-1` — **последняя ось**. `dim=0` — **первая ось**. `dim=1` — **вторая ось**.

## 5. Как получают данные

1. Загружают Pythia и токенизатор.
2. Берут тексты из `NeelNanda/pile-10k`.
3. Превращают тексты в ID токенов, оставляют 512 последовательностей по 128 токенов.
4. **Forward hook** перехватывает выход `model.gpt_neox.layers[3]` — **четвёртого блока** (нумерация с нуля).
5. Убирают первую позицию каждой последовательности: остаётся по 127 токенов.
6. Получают `512 × 127 = 65024` векторов, каждый длиной 512.
7. Сохраняют `X` в `pythia_activations.pt`.

**Hook** — функция, которая срабатывает на выходе слоя и позволяет сохранить промежуточный тензор, не меняя саму модель.

`torch.inference_mode()` — вычислять активации без градиентов. `.eval()` — режим оценки Pythia. Они нужны на этапе **сбора данных**, а не для обучения SAE.

## 6. Как обучают SAE

На каждом из 1000 шагов:

```python
x = X[torch.randint(len(X), (64,))]  # случайный батч 64 × 512
x_hat, acts = net(x)                 # прямой проход
loss = (x - x_hat).square().mean()   # MSE
optimizer.zero_grad()                # очистить старые градиенты
loss.backward()                      # вычислить новые градиенты
optimizer.step()                     # Adam обновляет параметры
```

**MSE (средняя квадратичная ошибка)** — среднее квадратов разностей между входом и восстановлением. Чем меньше MSE, тем точнее восстановление.

**Градиент** показывает, как меняется ошибка при изменении параметра. **Adam** использует градиенты для обновления весов и смещений. Параметры SAE — `W_enc`, `b_enc`, `W_dec`, `b_dec`; **Pythia не обучается**.

1000 шагов **не** равно 1000 эпохам: в одной эпохе обычно проходят всю обучающую выборку.

## 7. Метрики

### Explained Variance (EV)

В ноутбуке:

```text
EV = 1 - (средняя дисперсия ошибок по 512 координатам)
         / (средняя дисперсия входов по 512 координатам)
```

**Чем ближе к 100%, тем меньше разброс невосстановленной ошибки относительно разброса входа.** Здесь дисперсию считают по 512 координатам каждого токена, затем усредняют по батчу.

Важно: **EV ≠ процент точно восстановленных чисел; EV ≠ MSE.** Постоянное одинаковое смещение всех координат может давать высокую EV даже при большой ошибке MSE.

### Dead Latents Ratio

Доля латентов, которые **ни разу не имели ненулевой активации** за последние 500 шагов, то есть за `500 × 64 = 32000` предъявлений токенов.

```python
seen |= (acts != 0).any(dim=0)      # видел ли каждый латент активацию
ratio = (~seen).float().mean()      # доля неактивных
```

**Меньше — лучше** с точки зрения использования словаря. Но активность латента ещё **не доказывает**, что он кодирует понятную человеку фичу.

## 8. Почему первая версия «сломана» и как её исправили

| Проблема | Исправление |
|---|---|
| Начальные матрицы энкодера и декодера независимы | инициализируют согласованными транспонированными матрицами |
| Энкодер работает с сырым `x` | вычитают `b_dec`, анализируют отклонения от среднего |
| Декодер вначале выдаёт нулевой фон | `b_dec` инициализируют средним входных векторов |
| После Top-K остаются отрицательные значения | применяют ReLU к выбранным значениям |
| Векторы декодера без контроля длины | нормируют строки `W_dec` на L2-норму при декодировании |

**L2-нормировка на числах:** `[3, 4]` имеет длину `sqrt(3²+4²)=5`, поэтому единичный вектор — `[0.6, 0.8]`.

**Две оговорки:** `W_enc` и `W_dec.T` совпадают лишь **при инициализации** — после обучения матрицы независимы. После ReLU активных латентов может быть **меньше 32**.

## 10. Что запомнить в первую очередь

**Pythia даёт внутренние векторы → SAE переводит их в разреженные признаки → декодер восстанавливает исходные векторы → MSE обучает SAE → EV проверяет качество реконструкции, а Dead Latents проверяет использование словаря.**
