## Исправление BrokenTopKSAE

**SAE (Sparse Autoencoder)** — разреженный автоэнкодер, который преобразует входные активации в разреженный набор признаков и восстанавливает исходный вектор.

**Энкодер (Encoder)** пытается определить, какие признаки присутствуют в исходном векторе и насколько они активны.

**Декодер (Decoder)** пытается собрать исходный вектор обратно, используя найденные признаки.

В исходной реализации были три основные ошибки.

### 1. Отсутствие центрирования данных

Проблема: энкодер обрабатывал активации вместе с общим смещением, тратя часть возможностей на его представление.

Было:

```
self.b_dec = nn.Parameter(torch.zeros(d_model))
pre_acts = x @ self.W_enc + self.b_enc
```

Исправление:

```
self.b_dec = nn.Parameter(x_mean.clone())
pre_acts = (x - self.b_dec) @ self.W_enc + self.b_enc
```

При декодировании смещение добавляется обратно:

```
x_hat = acts @ W_dec_normalized + self.b_dec
```

Теперь SAE может сосредоточиться на отклонениях от среднего.

### 2. Отрицательные активации после Top-K

Проблема: Top-K выбирал наибольшие значения, среди которых могли быть отрицательные.

Было:

```
val, idx = torch.topk(pre_acts, self.k, dim=-1)
acts = torch.zeros_like(pre_acts).scatter_(-1, idx, val)
```

Исправление:

```
val, idx = torch.topk(pre_acts, self.k, dim=-1)
acts = torch.zeros_like(pre_acts).scatter_(-1, idx, torch.relu(val))
```

ReLU зануляет отрицательные значения:

Теперь активации неотрицательны, а число ненулевых признаков не превышает K.

### 3. Отсутствие нормализации декодера

Проблема: веса декодера могли произвольно увеличиваться, а активации уменьшаться без изменения восстановленного вектора.

Было:

```python
def decode(self, acts):
    return acts @ self.W_dec + self.b_dec
```

Исправление:

```python
def decode(self, acts):    
    W = self.W_dec / self.W_dec.norm(dim=1, keepdim=True)    
    return acts @ W + self.b_dec
```

Каждый вектор-строка декодера нормализуется до единичной L2-нормы:

Теперь направление признака задаётся единичным вектором, а активация определяет силу его вклада.

### 4. Улучшение инициализации весов

Было: энкодер и декодер получали независимые случайные веса.

```python
self.W_enc = nn.Parameter(torch.randn(d_model, d_sae) * 0.02)
self.W_dec = nn.Parameter(torch.randn(d_sae, d_model) * 0.02)
```

Стало:

```
W = torch.randn(d_sae, d_model)
W = W / W.norm(dim=1, keepdim=True)
self.W_enc = nn.Parameter(W.T.clone())
self.W_dec = nn.Parameter(W.clone())
```

При инициализации: $W_{\text{enc}}=W^T,\qquad W_{\text{dec}}=W$

Энкодер и декодер начинают обучение с согласованными направлениями, но затем их веса обучаются независимо.

### Итог

Исправления делают обучение SAE более устойчивым и помогают получать более качественное и интерпретируемое представление признаков.

Метрики качества:

- Explained Variance (EV) — насколько хорошо SAE восстанавливает изменчивость исходных активаций. Чем ближе к 1, тем лучше.

- Dead Feature Fraction — доля признаков, которые ни разу не активировались за период наблюдения. Чем меньше, тем лучше.

Важно: исправления улучшают архитектуру, но сами по себе не гарантируют отсутствие мёртвых признаков или высокую EV.

---

**Инференс (inference)** — использование нейросети с уже имеющимися параметрами для выполнения вычислений, без обучения её параметров.

## Алгоритм обучения SAE

```python
def train_sae(net, X):
    optimizer = torch.optim.Adam(net.parameters(), lr=1e-3)
    ev_history = []
    seen = torch.zeros(2048, dtype=torch.bool)

    for step in range(1000):
        x = X[torch.randint(len(X), (64,))]
        x_hat, acts = net(x)
        loss = (x - x_hat).square().mean()
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        if step >= 500:
            with torch.no_grad():
                ev = 1 - (x - x_hat).var(dim=-1, unbiased=False).mean() / x.var(dim=-1, unbiased=False).mean().clamp_min(1e-12)
                ev_history.append(ev.item())
                seen |= (acts != 0).any(dim=0)

    return sum(ev_history) / 500, (~seen).float().mean().item()
```

### Оптимизатор

```python
optimizer = torch.optim.Adam(net.parameters(), lr=1e-3)
```

**Оптимизатор** — это алгоритм, который изменяет параметры нейросети, чтобы уменьшать ошибку.

**Adam (Adaptive Moment Estimation)** — это алгоритм оптимизации, который изменяет параметры нейросети во время обучения, используя вычисленные градиенты.

`net.parameters()` — передаём ему обучаемые параметры нейросети, например матрицы `W_enc`, `W_dec` и векторы смещений.

`lr=1e-3` — устанавливаем learning rate (скорость обучения).

### Пропускаем данные через SAE

```
x_hat, acts = net(x)
```

Вызываем нейросеть `net`, передавая ей батч `x`.

В PyTorch эта запись вызывает метод `forward()` модели.

Для SAE из лабораторной работы он возвращает два результата:

`x_hat` — восстановленные входные активации.

`acts` — активации признаков внутри SAE после операции Top-K.

Размерности:

| Тензор  | Размерность  | Смысл                     |
| ------- | ------------ | ------------------------- |
| `x`     | `(64, 512)`  | Исходные активации        |
| `x_hat` | `(64, 512)`  | Восстановленные активации |
| `acts`  | `(64, 2048)` | Активации признаков SAE   |

### Вычисляем ошибку восстановления

```python
loss = (x - x_hat).square().mean()
```

Это одна из самых важных строк.

Задача SAE — научиться восстанавливать исходный вектор как можно точнее.

Для этого используем Mean Squared Error (MSE) — среднеквадратичную ошибку.

**Цель обучения: сделать `loss` как можно меньше.**

### Обнуляем старые градиенты

```python
optimizer.zero_grad()
```

В PyTorch вычисленные градиенты по умолчанию накапливаются.

Если не сбрасывать их, градиенты предыдущей итерации будут добавляться к новым.

Поэтому перед очередным вычислением градиентов мы очищаем старые значения.

Это не обнуляет веса нейросети, а только накопленные градиенты.

### Вычисляем градиенты

```
loss.backward()
```

Эта строка запускает обратное распространение ошибки (Backpropagation).

PyTorch вычисляет производные функции потерь по обучаемым параметрам SAE.

Для одного параметра \(w\) это выглядит так: $\frac{\partial L}{\partial w}$ 

Интуитивный смысл: как изменится ошибка, если немного изменить данный параметр?

Например: $\frac{\partial L}{\partial w}=2$

**Положительная производная означает, что небольшое увеличение \(w\) локально увеличивает ошибку. Поэтому для уменьшения ошибки выгодно двигаться в противоположную сторону.**

`backward()` вычисляет эти значения, но ещё не обновляет параметры.

### Обновляем параметры

```
optimizer.step()
```

Теперь Adam использует вычисленные градиенты для изменения весов и смещений нейросети.

### Вычисление дисперсии

`unbiased=False` означает, что при расчёте дисперсии используется деление на количество элементов \(n\), а не на \(n-1\).
