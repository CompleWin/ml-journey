Лабораторная работа 2 - Метод наискорейшего градиентного спуска

# Описание

Метод наискорейшего градиентного спуска это численный метод оптимизации, используемый для нахождения локального минимума функции. Он основан на движении в направлении антиградиента функции, что обеспечивает наискорейшее уменьшение её значения. Этот метод широко применяется в вычислительной математике, машинном обучении и других областях для решения задач минимизации, особенно когда аналитическое решение затруднительно или невозможно.

## Алгоритм

1. Выбираем начальные условия для X, как правило выбирается случайная точка из области допустимых значений решаемой задачи.

2. Найти градиент функции для которой ищется решение $\nabla f(X) = [f'(x)_{x_1}, f'(x)_{x_2},\dots,f'(x)_{x_n}]$

3. Находим оптимальный размер шага $\alpha$, такой что бы

   $\nabla f(X) = [f'(x)_{x_1}, f'(x)_{x_2},\dots,f'(x)_{x_n}]$

   т.е. надо найти такой *$\alpha$* при котором шаг уменьшения значения функции f(x) будет максимальным

4. Находим следующие значение x

   $\nabla f(X) = [f'(x)_{x_1}, f'(x)_{x_2},\dots,f'(x)_{x_n}]$

   где $x_{t+1}$ значение x на следующем шаге, а $x_t$ значение x не текущем шаге.

5. Проверим критерии остановки

   1. $||x_{t+1} - x_t|| \leq \epsilon_1$

   2. $|f(x_{t+1}) - f(x_t)| \leq \epsilon_2$

   3. $$|| \nabla f(x)|| \leq \epsilon_3 \nabla f(x)|| \leq \epsilon_3$$$

   Если выполняется любой из критериев, работа алгоритма останавливается
