# Мои записки

Этот репо — мои конспекты, разборы и лабораторные по дисциплинам, которые я изучаю или изучал: машинное обучение, линейная алгебра, компьютерное зрение, компьютерные сети, NumPy, Matplotlib.

Он не предназначен для других людей: структура, стиль и правила подстроены под меня. Но раз уж вы сюда зашли, можете изучать всё, что найдёте, и присылать пулл-реквесты. Особенно пригодятся:

- улучшения документов для работы с агентами в [docs/](docs/): если знаете, как сделать объяснения, конспекты или карточки лучше;
- ваши конспекты материалов, которые есть здесь или хорошо их дополняют.

## Работа с агентами

Конспекты, объяснения и карточки я пишу вместе с ИИ-агентом. Правила для него лежат в [docs/](docs/), а [AGENTS.md](AGENTS.md) говорит, какой файл читать для какой работы:

| Файл | Когда | Пример запроса |
|---|---|---|
| [docs/NOTES.md](docs/NOTES.md) | конспект материала | «напиши конспект по этому уроку» + HTML-файл урока |
| [docs/MENTOR.md](docs/MENTOR.md) | объяснение или разбор | «не понимаю эту формулу», «сделай лабу 4 и напиши объяснение в формате урока» |
| [docs/ANKI.md](docs/ANKI.md) | карточки Anki | «сделай карточки по новым пройденным темам» |

## Anki

Карточки делаются только по конспектам курсов и лекций. Каждая тема — отдельная колода `.apkg`.

```
anki/
├── decks/           колоды: <курс>/<тема>/, повторяют дерево колод в Anki
└── tools/           сборка, стиль картинок, реестр тем
```

В папке темы лежат `cards.txt` с карточками, `figures.py` с картинками, `media/` и готовый `<тема>.apkg`.

### Импорт

Двойной клик по `<тема>.apkg` или «Файл → Импорт» в Anki. Стили, картинки и тип заметки приедут вместе с колодой.

В настройках колоды курса лимит «Новых карточек в день» должен быть не меньше 25, иначе тема не откроется за один подход.

### Пересобрать колоду

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/). Из корня репозитория:

```bash
uv run --no-project --with matplotlib --with numpy python anki/decks/<курс>/<тема>/figures.py
```

```bash
uv run --no-project --with genanki python anki/tools/build.py anki/decks/<курс>/<тема> --preview
```

Без пути `build.py` пересоберёт все темы. `--preview` дополнительно создаёт `preview.html`, чтобы посмотреть карточки в браузере.

Прогресс повторения в Anki привязан к пути папки темы и к `ID` карточки, поэтому папки тем не переименовывают, а `ID` не меняют.

## Запуск ноутбуков

Всё запускается через [uv](https://docs.astral.sh/uv/getting-started/installation/).

На Windows:

```bash
winget install astral-sh.uv
```

На macOS:

```bash
brew install uv
```

### Папки со своим окружением

Если в папке есть `pyproject.toml` (например, лабы в `machine-learning/sfedu/labs/labN/`), окружение и версии библиотек зафиксированы в нём и в `uv.lock`. Из этой папки:

```bash
uv sync
```

Ноутбук `.ipynb`:

```bash
uv run jupyter lab
```

Файл marimo `.py`:

```bash
uv run marimo edit <файл>.py
```

`uv sync` сам скачает нужный Python и создаст `.venv`. Подробности для конкретной лабы — в её README.

### Папки без окружения

Для остальных ноутбуков (NumPy, Matplotlib, занятия, лабы по компьютерному зрению) хватает временного окружения, которое uv соберёт на лету:

```bash
uv run --no-project --with jupyterlab --with numpy --with matplotlib --with pandas jupyter lab
```

Для файлов marimo:

```bash
uv run --no-project --with marimo --with numpy --with matplotlib marimo edit <файл>.py
```

Если ноутбук просит ещё библиотеку, добавьте её через `--with <пакет>`.
